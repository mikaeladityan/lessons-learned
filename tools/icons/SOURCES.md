# Icon sources

- `bun`, `hono`, `rust`, `react`, `vite`, `tailwindcss`, `typescript`, `postgresql`, `redis`, `prisma`,
  `vitest`, `turborepo`: [Simple Icons](https://simpleicons.org) 13.21.0, CC0-1.0.
- `tanstack`: the official TanStack logo from
  [TanStack/tanstack.com](https://github.com/TanStack/tanstack.com) (`public/images/logos/logo-black.svg`).

Each logo is a trademark of its owner. This repo uses them only to name the tools a project used.
`tools/build-assets.mjs` reads these files and draws `assets/tested-stacks*.svg`.
